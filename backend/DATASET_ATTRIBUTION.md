# Dataset Attribution and Limitations

Cloud bootstrap source: [debojit01/fake-review-dataset](https://huggingface.co/datasets/debojit01/fake-review-dataset). Its Hugging Face dataset card marks the dataset MIT. Please check the card and paper before redistributing data independently.

This dataset contains 40k product reviews with labels CG and OR. These labels reflect a dataset construction task, not definitive evidence that a real-world user is fraudulent. The model is text-only and may not generalize to current AI-generated content or all review platforms. Display model confidence as a score from this model, never as proof of authenticity.
